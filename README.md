# Tic-Tac-Toe Game 🎮

A classic, interactive Tic-Tac-Toe game built for the web. This project is a straightforward implementation of the popular childhood game, playable directly in your browser. 

## ✨ Features

*   **Two-Player Mode:** Play against a friend locally on the same device. The game alternates turns between "O" and "X".
*   **Win Detection:** Automatically checks for all possible winning combinations (horizontal, vertical, and diagonal) and announces the winner.
*   **Game State Management:** Prevents players from overwricting already selected boxes or continuing to play after a winner has been declared.
*   **Reset & New Game:** Includes "Reset Game" and "New Game" functionality to quickly start over without refreshing the page.
*   **Clean UI:** Simple and intuitive user interface.

## 🛠️ Technologies Used

*   **HTML5:** Structure of the game board and UI elements.
*   **CSS3:** Styling, layout, and visual presentation.
*   **Vanilla JavaScript (ES6+):** Game logic, DOM manipulation, and event handling.

## 🚀 How to Run

1.  Clone this repository to your local machine.
2.  Open the `index.htm` file in any modern web browser.
3.  Start playing!

## 🎮 How to Play

1.  The game starts with Player "O".
2.  Click on any empty box on the 3x3 grid to place your mark.
3.  Players take turns placing their marks ("O" or "X").
4.  The first player to get 3 of their marks in a row (up, down, across, or diagonally) wins.
5.  If all 9 squares are full and no player has 3 in a row, the game is a draw.
6.  Click "Reset Game" or "New Game" at any time to clear the board.
